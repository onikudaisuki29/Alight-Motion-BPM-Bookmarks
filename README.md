必要なら「1拍あたりの分割」を変更します。たとえば8分音符なら 2、16分音符なら 4 です。

新規作成の場合は、「種類」で「プロジェクト」または「要素」を選び、プロジェクト名・解像度・FPSも入力します。既存XMLを選んだ場合は、そのXMLの種類と設定がそのまま使われます。

「プロジェクトのFPSにフレーム単位で合わせる」「既存のブックマークをすべて置き換える」には基本的にチェックで良いです。

保存先を確認し、「ブックマークを生成して保存」を押します。
